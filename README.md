# 장비주행성 검토 프로그램

업로드하신 실무 구조계산서 2종(`2_1_장비_주행성.xlsx`, `3_1_장비주행성.xlsm`)의 수식을
그대로 구현한 Streamlit 프로그램입니다. 모든 계산 결과는 원본 엑셀 값과 소수점 단위까지
일치하도록 검증되었습니다.

## 설치 및 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열리며 `http://localhost:8501` 에서 프로그램을 사용할 수 있습니다.

## 구성

- **방법 A : Meyerhof-Hanna 지지력식(토목섬유 보강)** — `2_1_장비_주행성.xlsx` 기반.
  원지반 지지력(qa)을 이론식으로 직접 산정합니다.
- **방법 B : 하중분산 응력법** — `3_1_장비주행성.xlsm`의 `1-1.원지반 작용응력` 시트 기반.
  평판재하시험 등으로 확인된 허용지지력을 직접 입력해 비교합니다.

## 사용 방법

1. 왼쪽 사이드바에서 계산서 표지 정보(PROJECT, SHEET NO 등), 검토 방법, 지반정수를 입력합니다.
2. 본문의 장비 테이블에서 검토할 장비를 체크하고, 필요 시 제원(폭/길이/접지압)과
   **복토두께(H)**를 장비별로 자유롭게 수정합니다. 행 추가/삭제도 가능합니다.
3. **[▶ 검토 실행]** 버튼을 눌러 결과표와 그래프를 확인합니다.
4. **🖨️ 인쇄용 보기**를 열면 원본 계산서와 동일한 형식(표지+이론+결과표)의 인쇄용
   레이아웃이 표시됩니다. 브라우저 인쇄(Ctrl+P)로 PDF 저장하거나 바로 출력하세요.
5. 결과표는 엑셀로도 다운로드할 수 있습니다.

## 참고 (한계 및 확인 필요 사항)

- 장비 데이터베이스의 기본값은 업로드된 두 계산서에 나온 값을 통합한 것입니다.
  실제 프로젝트의 지반조건/장비제원과 다를 경우 표에서 직접 수정해 사용하세요.
- 방법 A의 토목섬유 허용인장력(T)은 원본 엑셀에서 0으로 설정되어 있었습니다(보강효과 미반영).
  실제 Geotextile 강도를 반영하려면 사이드바에서 T값을 입력하세요.
- Ks(펀칭전단계수) 조견표는 φ1=20~50° 구간만 제공되며, 범위를 벗어나면 양 끝값으로 고정됩니다.
